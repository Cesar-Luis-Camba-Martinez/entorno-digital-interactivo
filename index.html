Ecuación de Primer Grado

Una ecuación lineal tiene la forma general donde el exponente de la variable es uno:

Ecuación Lineal General:
$$ax + b = 0$$
Despeje de la incógnita:
$$x = \frac{-b}{a} \quad \text{donde } a \neq 0$$

🧪 Laboratorio Virtual de: Ecuación Lineal

Ecuación de Segundo Grado

Expresión estándar y fórmulas fundamentales de la ecuación cuadrática:

Ecuación General:
$$ax^2 + bx + c = 0$$
Discriminante ($\Delta$):
$$\Delta = b^2 - 4ac$$
Fórmula General (Bhaskara):
$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

🧪 Laboratorio Virtual de: Ecuación Cuadrática

Sistema de Ecuaciones Lineales $2 \times 2$

Dos ecuaciones lineales con dos incógnitas:

Forma del Sistema:
$$\begin{cases} a_1x + b_1y = c_1 \\ a_2x + b_2y = c_2 \end{cases}$$

🧪 Laboratorio Virtual de: Sistema $2 \times 2$

Ecuación Polinómica de Tercer Grado (Cúbica)

Expresión analítica de un polinomio cúbico con coeficientes reales:

Forma Estándar Cúbica:
$$ax^3 + bx^2 + cx + d = 0 \quad \text{con } a \neq 0$$
Método de Resolución:
$$\text{Teorema de la Raíz Racional } \rightarrow \text{División Sintética (Ruffini) } \rightarrow \text{Fórmula Cuadrática}$$

🧪 Laboratorio Virtual de: Ecuación Cúbica

Ecuación Polinómica de Cuarto Grado (Cuártica)

Expresión algebraica polinómica con término de mayor grado igual a cuatro:

Forma Estándar Cuártica:
$$ax^4 + bx^3 + cx^2 + dx + e = 0 \quad \text{con } a \neq 0$$
Estrategia de Resolución:
$$\text{Raíz Racional } \rightarrow \text{Ruffini (1° nivel)} \rightarrow \text{Ruffini (2° nivel)} \rightarrow \text{Fórmula Cuadrática}$$

🧪 Laboratorio Virtual de: Ecuación Cuártica

Ecuación con Valor Absoluto

Expresión algebraica que contiene una variable dentro de las barras de valor absoluto:

Forma General:
$$|ax + b| = c$$
Propiedad Fundamental ($c \ge 0$):
$$ax + b = c \quad \text{o} \quad ax + b = -c$$

🧪 Laboratorio Virtual de: Valor Absoluto
