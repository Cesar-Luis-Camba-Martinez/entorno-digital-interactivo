Este documento contiene las plantillas estandarizadas para el registro, reporte y seguimiento de incidencias técnicas y pedagógicas dentro del entorno digital interactivo.

---

## 1. Plantilla: Reporte de Incidencia Técnica (Hardware / Software)

> **Uso:** Utilizar esta plantilla para reportar fallos en equipos, problemas de conectividad o errores en aplicaciones del sistema.

```markdown
### Reporte de Incidencia Técnica

* **ID de Incidencia:** [INC-001]
* **Fecha y Hora:** [DD/MM/AAAA - HH:MM]
* **Reportado por:** [Nombre completo / Rol: Estudiante, Docente, Administrador]
* **Categoría:** [ Hardware | Conectividad / Red | Plataforma LMS | Software ]
* **Ubicación / Entorno:** [Aula Virtual, Laboratorio, Conexión Remota, etc.]
* **Nivel de Urgencia:** [ Baja | Media | Alta | Crítica ]

#### Descripción del Problema
[Describa detalladamente qué sucedió, qué acción estaba realizando antes del error y proporcione el mensaje de error exacto si aplica.]

#### Pasos para Reproducir el Error
1. 
2. 
3. 

#### Evidencias (Opcional)
* [Adjuntar capturas de pantalla, archivos de registro (logs) o enlaces de referencia]

---
* **Estado del Reporte:** [ Pendiente | En proceso | Resuelto | Cancelado ]
```

## 2. Plantilla: Incidencia Pedagógica o de Acceso al Aula Virtual

> **Uso:** Utilizar para problemas con el acceso a recursos académicos, entrega de tareas, matriculación o interacción en plataformas educativas.

```markdown
### Reporte de Incidencia Pedagógica

* **ID de Incidencia:** [EDU-001]
* **Fecha y Hora:** [DD/MM/AAAA - HH:MM]
* **Usuario Afectado:** [Nombre completo del estudiante o docente]
* **Asignatura / Módulo:** [Nombre del curso o asignatura]
* **Tipo de Error:** [ Acceso a Materiales | Entrega de Evaluación | Permisos de Usuario | Videoconferencia ]

#### Detalle de la Solicitud / Problema
[Explique el inconveniente pedagógico o la dificultad de acceso presentada.]

#### Solución Temporal o Recomendación Inmediata
[Detallar si se ofreció una vía alternativa para no interrumpir el proceso de aprendizaje.]

---
* **Atendido por:** [Nombre del tutor o administrador del aula]
* **Estado:** [ Abierto | En Revisión | Solucionado ]
```

## 3. Plantilla: Bitácora de Resolución y Cierre de Incidencias

> **Uso:** Utilizar por el equipo de soporte o administración para documentar la solución aplicada a una incidencia previa.

```markdown
### Bitácora de Resolución de Soporte

* **ID de Incidencia Asociada:** [INC-001 / EDU-001]
* **Fecha de Cierre:** [DD/MM/AAAA - HH:MM]
* **Técnico / Responsable:** [Nombre del encargado del soporte]

#### Diagnóstico
[Explicación técnica de la causa raíz que provocó la incidencia.]

#### Acción Correctiva / Solución Aplicada
[Descripción paso a paso de la solución o parche aplicado para resolver el problema.]

#### Confirmación y Conformidad
* [x] Se notificó al usuario la resolución.
* [x] El usuario confirmó el correcto funcionamiento.
* **Comentarios Finales:** [Observaciones adicionales o recomendaciones para prevenir el error en el futuro]
```
