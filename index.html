Ecuación con Valor Absoluto

Modela distancias algebraicas sobre la recta real respecto al origen o un punto de referencia.

Forma General:
$$|ax + b| = c$$
Propiedad Fundamental ($c \ge 0$):
$$ax + b = c \quad \text{o} \quad ax + b = -c$$
Despeje Paso a Paso de las Soluciones ($a \neq 0, c \ge 0$):
$$\text{Caso 1 (+): } ax + b = c \implies ax = c - b \implies x_1 = \frac{c - b}{a}$$
$$\text{Caso 2 (-): } ax + b = -c \implies ax = -c - b \implies x_2 = \frac{-c - b}{a}$$
Fundamento Pedagógico: Dado que el valor absoluto representa una distancia y por definición $c \ge 0$, la ecuación se descompone en dos casos lineales independientes. Se despeja la variable $x$ al restar el término $b$ en ambos miembros y dividir para el coeficiente $a$. Si $c < 0$, la ecuación carece de solución real ($\mathcal{S} = \emptyset$).

Ecuación Lineal de Primer Grado

Representa una relación de proporcionalidad de primer grado cuya solución es un único valor en la recta real.

Forma General:
$$ax + b = 0$$
Despeje Algebraico ($a \neq 0$):
$$ax = -b \implies x = -\frac{b}{a}$$
Fundamento Pedagógico: Se traspone el término independiente $b$ restándolo en ambos lados y se divide entre el coeficiente principal $a$.

Ecuación Cuadrática o de Segundo Grado

Modela trayectorias parabólicas y relaciones polinómicas de grado 2.

Forma General:
$$ax^2 + bx + c = 0 \quad (a \neq 0)$$
Fórmula General:
$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
Discriminante ($\Delta$):
$$\Delta = b^2 - 4ac$$
Fundamento Pedagógico: Si $\Delta > 0$ existen dos soluciones reales distintas; si $\Delta = 0$ existe una única solución real doble; si $\Delta < 0$ las soluciones pertenecen al conjunto de los números complejos.
